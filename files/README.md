# CSc 8830 — Module 2: Object Dimension Measurement via Perspective Projection

Measure the real-world 2D size of an object from a single smartphone photo,
using camera calibration + the pinhole projection equations, and validate the
accuracy over 20 measurements.

**Repo link:** https://github.com/Dhanush-0017/Computer-Vision-CSc-8830

## Structure
```
camera-measurement/
├── README.md
├── requirements.txt
├── src/
│   ├── calibrate.py   # Step 1: camera calibration (OpenCV chessboard)
│   ├── measure.py     # Step 2: pixels -> real dimensions (perspective projection)
│   └── validate.py    # Step 3: 20 measurements + error statistics
├── data/
│   ├── calibration_images/   # <- put your chessboard photos here
│   └── measurements.csv      # <- fill with your 20 validation measurements
├── calibration/
│   └── camera_params.npz     # generated by calibrate.py
└── docs/
    └── theory.md             # two-view geometry derivation (for the PDF)
```

## Setup
```
pip install -r requirements.txt
```

## Step 1 — Calibrate
Print a chessboard, take 15–25 photos with your phone from varied angles, drop
them in `data/calibration_images/`, then:
```
cd src
python calibrate.py --images ../data/calibration_images --rows 6 --cols 9 --square 25.0
```
Aim for a reprojection error under ~0.5 px.

## Step 2 — Measure
Photograph an object at a known distance Z (> 2 m). Point the camera straight at
it so the measured face is roughly perpendicular to the optical axis. Then:
```
python measure.py --calib ../calibration/camera_params.npz --Z 2500 --image ../data/obj.jpg
```
(Click the two endpoints of the dimension you want. Z is in mm.)

## Step 3 — Validate
For 20 measurements, record `Z_mm, u1, v1, u2, v2, gt_mm` (ground truth from a
tape measure) in `data/measurements.csv`, then:
```
python validate.py --calib ../calibration/camera_params.npz --csv ../data/measurements.csv --plot
```
Reports MAE, RMSE, MAPE, mean/std of signed error, max error, and a
measured-vs-ground-truth plot.
